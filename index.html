Lines PNG goes on its own layer in Procreate, set as Reference, so ColorDrop fills underneath it.

Colour by number in Procreate: import Lines PNG (set it as Reference), add a layer below it to colour on, then import Numbers PNG on top. ColorDrop only sees the lines, so the numbers never block a fill. Hide the numbers layer when you're done.
